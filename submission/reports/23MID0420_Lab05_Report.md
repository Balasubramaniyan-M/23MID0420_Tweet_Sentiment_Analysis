## 2. Problem Framing

### 2.1 Task Definition
- **Prediction Unit:** Single tweet
- **Input Features:** Tweet text with entity context (US airline handle/name)
- **Target Label:** Multiclass sentiment: `negative` (0), `neutral` (1), or `positive` (2)
- **Task Type:** Supervised multiclass text classification

### 2.2 Business Context
Potential applications include automated product feedback analysis, service-quality tracking across airline brands, proactive crisis/delay detection, and campaign sentiment monitoring.

### 2.3 Responsible Decision Boundaries
Predictions from this model represent statistical text associations, not definitive measures of overall customer satisfaction. Social media users represent an active subset of customers who disproportionately tweet to report disruptions. Consequently, predictions must serve as analytical screening signals subject to human review, not autonomous punitive or decision-making systems.

- **Timeframe:** February 2015
- **Size:** 14,640 rows, 15 columns
- **License:** CC BY-NC-SA 4.0 Open Data

### 3.2 Target Class Distribution
The dataset exhibits pronounced class imbalance reflecting social-media complaint tendencies:

| Class | Sample Count | Proportion (%) |
|---|---|---|

The majority-to-minority imbalance ratio is 3.88:1 (`negative` to `positive`). This severe imbalance dictates that **Macro F1** (unweighted mean across classes) serves as the primary optimization and model selection metric.

### 3.3 Data Governance & Leakage Prevention Audit
An automated governance audit identified and permanently excluded 11 columns from the feature set:

- **Leakage Risk Columns (Excluded):**
  - `airline_sentiment_confidence` (directly discloses annotator certainty of target)
  - `negativereason` (post-hoc explanation of negative label)
  - `negativereason_confidence` (confidence score of explanation)
  - `airline_sentiment_gold` (alternate ground truth)
  - `negativereason_gold` (alternate reason ground truth)
- **Privacy & Metadata Columns (Excluded):**
  - `name` (Twitter user handle)
  - `tweet_id` (unique identifier)
  - `retweet_count` (social engagement metadata)
  - `tweet_coord` (geographic coordinates)
  - `tweet_location` (freeform user profile location)
  - `user_timezone` (user timezone)

Only `text` was utilized as the modeling input, and `airline` was preserved exclusively for post-evaluation entity analysis.

## 5. Tweet Preprocessing Strategy

### 5.1 Minimal Preprocessing (Primary Pipeline)
To preserve essential sentiment signals, the minimal normalization strategy applies only non-destructive noise standardizations:
1. URL replacement: `https?://\S+` -> `<URL>`
2. Mention anonymization: `@\w+` -> `<USER>` (satisfying privacy compliance)
3. Repeated character reduction: Excess character repetitions truncated to maximum 3 (`sooooo` -> `sooo`)
4. Lowercasing: Standardized for consistent vocabulary matching
5. Whitespace normalization: Stripping excess whitespace

### 5.2 Signal Preservation
- **Emojis preserved:** Positive (`😊`, `❤️`) and negative (`😡`, `👎`) emoticons retained.
- **Hashtags preserved:** Topical hashtags (`#fail`, `#love`, `#delayed`) retained.
- **Punctuation intensity preserved:** Exclamation and question marks retained (`!!!`, `???`).
- **Negation tokens preserved:** `not`, `no`, `never`, `n't` intact for bigram capture.

## 6. Split Strategy and Leakage-Safe Architecture

### 6.1 Stratified Disjoint Split
Using a fixed global seed (`SEED = 42`), the dataset was partitioned into three disjoint subsets:

| Split | Count | Proportion | Negative | Neutral | Positive |
|---|---|---|---|---|---|
| **Train** | 10,248 | 70.0% | 6,425 (62.7%) | 2,169 (21.2%) | 1,654 (16.1%) |
| **Validation** | 1,464 | 10.0% | 918 (62.7%) | 310 (21.2%) | 236 (16.1%) |
| **Test (Locked)** | 2,928 | 20.0% | 1,835 (62.7%) | 620 (21.2%) | 473 (16.1%) |

Disjointness verification confirmed Train ∩ Val = ∅, Train ∩ Test = ∅, and Val ∩ Test = ∅.

### 6.2 Pipeline Containment
All text vectorization steps (`TfidfVectorizer`) were strictly wrapped inside scikit-learn `Pipeline` objects. Vocabulary fitting occurs exclusively on the training folds during cross-validation and on the combined training set (`Train + Val` = 11,712 samples) for final fitting, guaranteeing zero data leakage from the test split.

## 7. Baseline Models

### 7.1 Dummy Classifier (Most Frequent Class)
- **Strategy:** Always predict `negative` (majority class).
- **Test Performance:** Accuracy = 0.6267, Macro Precision = 0.2089, Macro Recall = 0.3333, **Macro F1 = 0.2568**, Weighted F1 = 0.4829.
- **Diagnosis:** Demonstrates that high naive accuracy (62.67%) is deceptive in imbalanced domains due to complete failure on minority classes (0% recall on neutral and positive).

### 7.2 VADER (Valence Aware Dictionary for sEntiment Reasoning)
- **Strategy:** Rule-based lexicon mapping ([-1.0, +1.0] compound polarity thresholded at ±0.05).
- **Test Performance:** Accuracy = 0.4949, Macro Precision = 0.5296, Macro Recall = 0.5662, **Macro F1 = 0.4656**, Weighted F1 = 0.5177.
- **Diagnosis:** Fails on domain-specific airline terminology (`delayed`, `gate change`, `rebooked`) and subtle sarcasm (`"Thanks for leaving my bag in Denver"`).

## 9. Model Selection Decision

**Selected Architecture:** **Logistic Regression Pipeline** (`TweetPreprocessor(strategy='minimal')` -> `TfidfVectorizer(ngram_range=(1,2), sublinear_tf=True, max_features=50000)` -> `LogisticRegression(C=1.0, class_weight='balanced', solver='lbfgs')`).

**Justification:**
1. Achieved the highest cross-validation Macro F1 (0.7467 ± 0.0096) across all folds.
2. Exhibited superior stability (std = 0.0096 vs. 0.0123 for LinearSVC).
3. Balanced class weighting effectively counteracted the 3.88:1 class disparity without sacrificing minority class recall.
4. Model selection was finalized strictly on training data prior to unfreezing the test set.

## 14. Responsible Social-Media Analytics

1. **Privacy Safeguards:** PII fields (`name`, coordinates, timezone) permanently excluded; all display examples redacted (`<USER>`, `<URL>`).
2. **Sampling Bias:** Data captures Twitter activity during February 2015; Twitter demographics skew younger and toward vocal complaints.
3. **Annotation Inconsistencies:** Boundary ambiguity between neutral information sharing and mild dissatisfaction.
4. **Actionable Limitations:** The model should never trigger autonomous customer penalties or employee disciplinary actions.

---

## 15. Limitations & Future Work

1. **Bag-of-Words Horizon:** TF-IDF captures local n-grams but cannot model long-range discourse dependencies or syntactic reversals.
2. **Sarcasm Detection:** Sarcasm requires pragmatic reasoning beyond unigram/bigram statistics.
3. **Temporal Drift:** Terminology and social media shorthand evolve; retraining is necessary for contemporary production deployment.
4. **Future Recommendation:** Exploration of lightweight Transformer architectures (e.g., RoBERTa-Tweet) with calibration layers for high-stakes routing.
