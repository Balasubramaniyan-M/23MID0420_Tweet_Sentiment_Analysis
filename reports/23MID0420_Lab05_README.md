## Objective

Develop, compare, evaluate, interpret, and document sentiment classifiers that predict the sentiment expressed in tweets toward products, brands, and services (specifically US airlines).

## Task Definition

- **Type:** Supervised multiclass text classification
- **Input:** Tweet text
- **Target:** Sentiment label (negative / neutral / positive)
- **Unit:** One tweet
- **Dataset:** Twitter US Airline Sentiment (~14,640 tweets)

## Models Implemented

| Model | Type | Description |
|---|---|---|
| DummyClassifier | Baseline | Most-frequent class predictor (performance floor) |
| VADER | Baseline | Lexicon-based social media sentiment (no training) |
| Logistic Regression | Classical ML | TF-IDF (1,2)-gram → Logistic Regression |
| LinearSVC | Classical ML | TF-IDF (1,2)-gram → Calibrated LinearSVC |
| MultinomialNB | Classical ML | TF-IDF (1,2)-gram → Multinomial Naive Bayes |

## Reproducibility

- **Random Seed:** 42
- **Split Strategy:** Stratified train (70%) / val (10%) / test (20%)
- **CV:** 5-fold StratifiedKFold with shuffle=True, random_state=42
- **Model Selection Metric:** Macro F1
- All TF-IDF vectorizers are inside sklearn Pipelines (no leakage)
- The test set was NOT used for model selection

## Limitations

1. **Sampling bias**: Only tweets from February 2015 about US airlines
2. **Annotation noise**: Crowdsourced labels may contain errors, especially at class boundaries
3. **Sarcasm/irony**: Not explicitly handled by TF-IDF features
4. **Domain specificity**: Models trained on airline tweets may not generalize to other products
5. **Temporal shift**: Language and sentiment patterns may have changed since 2015
6. **Platform bias**: Twitter users are not representative of all customers

## Responsible Use

- Predictions are analytical signals, NOT objective truth
- Human oversight is required before any consequential business decisions
- Raw tweet percentages should not be interpreted as population-level customer sentiment
- No individual user profiling, tracking, or discriminatory use is intended or supported
- Private user information (handles, coordinates, locations) is excluded from modeling
